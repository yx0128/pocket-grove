## Design QA

- **Sky:** CSS radial sun + blue→cream gradient; no world-space sky dome (which would render orange with the top-down camera).
- **Board:** uniform instanced tiles in View; 18 crisp grid bars only in Build/Remove.
- **Flat tiles:** visible above the island surface after fixing the RoundedBox radius (`0.18 → 0.06`).
- **Validity:** `HIGHLIGHT_Y = 0.103` keeps the tint above flat grass/path/pond tops.
- **Ghost:** lifted 0.06, ~68% opacity, green/red ring; non-raycast.
- **Clouds:** three low clouds visible in the default framing; high clouds for orbit.
- **Shadows:** 2048² PCFSoft; soft contact under miniatures.
- **Typography:** system rounded stack, tabular coin numerals.
- **1280 × 720:** top bar, sidebar, hotbar, and mode hint fit without overlap; island remains fully visible.

## Known limitations

- **Desktop-first.** Touch gestures and a compact mobile layout are not a product target. The UI is responsive enough to render, but the 8 × 8 builder is designed for a laptop/PC.
- **localStorage only.** Clearing site data or changing browsers loses the world. No export/import yet.
- **No backend.** No accounts, sync, or multi-device support by design.
- **10 items.** The brief asked for 10+; the ten listed items are implemented. Adding more requires the extension steps in AGENTS.md.
- **No undo.** Removal returns the item, but there is no multi-step undo history.
- **Audio autoplay.** Sound starts only after the first user gesture, per browser policy.
- **Headless screenshots** freeze animations to avoid throttling artifacts; this is a QA-only behavior and does not affect the app.
- **Session metrics are a snapshot.** OpenCode session rows update after each model step, so `STATE.md` is slightly behind the closing message.
